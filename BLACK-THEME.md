# Yugma — Final Black Professional UI

The client UI now uses a pure-black visual system with white typography and a restrained violet accent. Legacy orange, light-blue, and white control surfaces were overridden in the final CSS layer.

## Local setup

1. Create `server/.env` from `server/.env.example`.
2. Create `client/.env` from `client/.env.example`.
3. Run `npm install` in the root, then `npm install` inside `server` and `client`.
4. Start with `npm run dev`.

Do not commit real `.env` files or production credentials.
